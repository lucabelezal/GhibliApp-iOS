# Exemplos de Conventional Commits (pt-BR)

## feat
feat(ui): adiciona animação de carregamento na tela inicial
feat(domain)!: altera modelo de usuário para múltiplos perfis

## fix
fix(data): corrige bug ao salvar favoritos
fix(ui): ajusta layout do botão de busca

## docs
docs: atualiza README com instruções de build

docs: corrige erros de digitação na documentação

## infra
infra: adiciona script de deploy automatizado

## chore
docs(chore): atualiza dependências do projeto

## test
test: adiciona testes unitários para o repositório de filmes

test(ui): corrige teste de snapshot da tela de detalhes

## PR (Pull Request)
**O quê:** Adiciona tela de favoritos
**Por quê:** Permitir que usuários salvem filmes preferidos
**Como testar:** Acesse a aba de favoritos e verifique se os filmes são listados corretamente
